# 名臣与宰相思维专区

> 深入本质，一通百通。 · Zero Wong

十位中国历史名臣与宰相的思维模型，每位人物拥有独立 Skill 仓库。本集合包括宰相、改革家和总督重臣，是代表性选取，不是历史地位排名，也不把所有人的职位统称为丞相。

## 怎样选择

- 组织供给与长期建设：管仲、萧何、曾国藩。
- 合作利益与职责分工：陈平。
- 异议、证据与纠错：魏徵、狄仁杰、司马光。
- 制度改革与执行激励：商鞅、王安石、张居正。

## 怎样安装与调用

进入人物仓库，下载以仓库名命名的 ZIP 完整包，解压后将同名文件夹放入 Codex 的 skills 目录。新开会话后提出“用萧何视角分析这个组织问题”。根目录 SKILL.md 用于预览，完整研究笔记保存在 ZIP 内。

提供目标、事实、限制与备选方案，要求区分史料事实、框架归纳与现代迁移。可以让两位人物分别分析同一问题，再比较结论。

## 依据与边界

以传世史料和历史研究为依据。短标题和现代提问是分析概括，不是人物原话。保留反例、失败、权力压制与制度副作用，不将古代惩罚、欺骗或政治清洗直接转为现代建议。《管子》《商君书》等文本的归属边界见各完整包。详细来源、材料归属和审校记录随包保存。
